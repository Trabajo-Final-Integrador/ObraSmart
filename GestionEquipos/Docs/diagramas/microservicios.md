# Diagrama de Microservicios – ObraSmart (Vista parcial)

Este documento describe cómo se ubica el microservicio **GestionEquipos** dentro de la arquitectura de microservicios de ObraSmart.

Microservicios principales relacionados:

- **Gateway**  
- **GestionEquipos**  
- **GestionReparaciones**  
- **GestionGeolocalizacion**  
- **GestionStock**  
- **GestionReportes**  
- **GestionLogin / Seguridad**  
- **Frontend Angular**

El diagrama debe mostrar:

- El API Gateway como punto de entrada.  
- Las llamadas desde el frontend hacia GestionEquipos.  
- Las relaciones de GestionEquipos con los demás microservicios (consumo/provisión de datos).  

Una vez modelado, exportar el diagrama como `microservicios-obrasmart.png`.
